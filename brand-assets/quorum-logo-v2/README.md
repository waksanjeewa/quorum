# Quorum Logo V2

Direction: consensus table.

The mark blends the two strongest brand metaphors:

- six evenly spaced seats for the quorum / roundtable of agents;
- a faceted center for convergence into one decision;
- one amber seat as the consensus signal.

Palette:

- background: `#0A0F12`
- primary: `#10B981`
- secondary: `#0EA5A4`
- cool accent: `#22D3EE`
- warm accent: `#F59E0B`
- text: `#E6F1EE`
