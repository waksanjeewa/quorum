Not a router. A team.

Other tools pick one model per request. Quorum makes several models collaborate on one goal — and keeps going when limits hit.

♻️

Never runs out

Each seat is a failover chain. Hit your Claude limit mid-thought? Codex reads the shared transcript and continues the same seat. Then a free model. The session survives.

🗳️

Real deliberation

Proposer proposes, critic attacks (no early rubber-stamps), arbiter decides. Blind-judged, the roundtable beat a single model of the same kind.

🔨

It actually builds

Plans become code: executors edit files in isolated git worktrees, run your acceptance checks, get reviewed, and merge — in parallel, across independent tasks.

💸

Frugal by default

Free models (Ollama, OpenRouter :free) do the bulk drafting; your paid models are spent only on verifying and improving. Hard cost + time caps.

🔒

Local-first & private

No server, no accounts, no telemetry. Prompts and transcripts stay on your machine; API keys live in your OS Keychain, never in a file.

🧑‍💻

You're at the table

Watch the debate live in a shell or web dashboard, drop a message in mid-run without pausing, tweak models in a visual settings panel, and a big red STOP.

⏸️

Resumable

Everything is plain files on disk. Close your laptop, come back, quorum resume — it picks up exactly where it left off.

🔁

Bring your logins

Reuses your existing Claude Code and Codex logins — no API keys required for the models you already pay for.

🧩

Extensible

Any OpenAI-compatible endpoint — OpenRouter, a local gateway, or a lab API — plugs in. New agent platforms need one small adapter.

Get started in a minute

Needs Node ≥ 20 and git. Reuse the logins you already have.

1
Install
npm install -g quorum  ·  or from source: curl -fsSL https://raw.githubusercontent.com/waksanjeewa/quorum/main/install.sh | bash
2
Log in to models you want
claude login   codex login   or paste an API key in setup (saved to your Keychain), or ollama serve for free local.
3
Go
quorum opens an interactive shell — pick models with /models, then just type a goal like “build me a CSV-to-JSON CLI.” In a git repo it plans and builds.
