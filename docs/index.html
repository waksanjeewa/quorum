How it works

Quorum itself is the conductor — not an AI. It decides who speaks, hands off the moment a model hits its limit, assigns the building, runs the checks, and merges. The models just take seats.

Proposer

Advances one concrete approach toward your goal. Decisive and specific — it moves the work forward.

Critic

Hunts for weaknesses, gaps, and risks — and can't rubber-stamp early. This is where mistakes get caught before they ship.

Arbiter

Weighs the proposal against the critique, breaks ties, and calls when it's genuinely good enough.

Claude and Codex are the executors — the only models that can edit files and build. Free models (Ollama, OpenRouter) deliberate, draft, and verify. Every seat is a failover chain: hit a limit, and the next model reads the same shared transcript and continues that seat exactly where it left off — so no single model owns the work.

Get started in a minute

The installer can bootstrap Node ≥20, npm, git, Python 3, pnpm/Corepack, and Linux secret-tool. Reuse the model logins you already have.

1
Install from source (npm one-liner coming soon)
curl -fsSL https://raw.githubusercontent.com/waksanjeewa/quorum/main/install.sh | bash
or: git clone https://github.com/waksanjeewa/quorum && cd quorum && ./install.sh
2
Log in to models you want
claude login   codex login   or paste an API key in setup (saved to your Keychain), or ollama serve for free local.
3
Go
quorum opens an interactive shell — type / for the arrow-key command menu, pick models with /models, then enter a goal like “build me a CSV-to-JSON CLI.” If the goal is unclear, Quorum asks a follow-up first; in a git repo it plans and builds.
